# Anchor — Axmra Commercial Directory

## Quick Start
When the user says "Dashboard", "dashboard", "anchor", or "start":
1. Launch the GUI: Run `python3 anchor_gui.py` (starts a local web server at http://localhost:8777 and opens the browser)
2. Give a brief status summary (date, active tasks, upcoming deadlines, inbox count)
3. The GUI is fully interactive — all changes save to markdown files automatically and are logged.

**IMPORTANT:** `anchor_gui.py` is the preferred interface. It syncs both Anchor PSU and Anchor Axmra automatically.

## Fallback (if GUI can't launch)
Run `python3 anchor.py dashboard`, present dashboard.html, and use text commands.

## File Structure
```
anchor_gui.py           ← Standalone GUI (local web server + browser dashboard)
anchor.py               ← CLI engine (reads/writes markdown, generates HTML)
dashboard.html          ← Static HTML dashboard (auto-generated by anchor.py)
CLAUDE.md               ← This file
.anchor/
  DASHBOARD.md          ← Commercial dashboard with active priorities
  PROJECTS.md           ← PROPRIETARY — detailed commercial project info
  INBOX.md              ← Commercial inbox
  archive/              ← Completed items
  logs/                 ← Activity logs (auto-created)
```

## Important Rules
- **PROJECTS.md contains proprietary information.** Never share outside this session.
- **Both directories sync automatically.** PSU and Axmra are always kept in sync.
- **anchor_gui.py is the primary interface.** Reads/writes markdown directly.
- **Markdown files are the source of truth.**
- The primary directory with all domain files is Anchor PSU.
