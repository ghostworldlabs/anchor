Subject: Updating Anchor to v1.3.2

Hi everyone,

The [Anchor v1.3.2 update](https://github.com/johncliechty/anchor-plus-skills) is available, with dashboard and bundled Trio/Foundry improvements.

If you have an existing `anchor-plus-skills` Git checkout:

1. Finish any running jobs.
2. Open ordinary PowerShell in that folder and run `git pull --ff-only`.
3. Only if that succeeds, run `.\onboard.cmd` to register the newly bundled skills.
4. Restart Windows once, then open the **Anchor Dashboard** icon.

These core setup commands don't require administrator access.

Keep your existing folder and data. If your copy came from the older Anchor repository or a ZIP, contact me for migration help before using these commands. If an upgrade command fails, send me the message before trying further changes. The [onboarding guide](https://github.com/johncliechty/anchor-plus-skills/blob/main/USER-ONBOARD.md) is available for reference.

Try a small project: researchPrime investigates, Crucible plans, and Foreman builds. Foundry adds focused review and advisory helpers.

**Please skip optional Python/R Jupyter notebook-host setup; it is still being repaired.**

I'd appreciate feedback on confusing steps, useful features, and anything missing. You're welcome to try and use Anchor as an invited collaborator; please don't redistribute it. All rights reserved.
