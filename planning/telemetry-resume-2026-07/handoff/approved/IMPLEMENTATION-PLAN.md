# Anchor — Honest Telemetry + Warm Resume — Implementation Plan (Foreman-ready)

test-command: python -m pytest tests/ -v

**North Star:** Every Anchor session — interactive ConPTY or one-shot job — leaves an honest, machine-verified trail of what it cost and what it accomplished, so the project rollup's numbers mean 'measured truth, not zero-by-omission,' and clicking ANY session tile reliably opens a warm terminal that narrates what was done, what was produced, and what comes next.

## Success criteria
- Interactive PTY sessions capture real usage: a usage-capture seam on the terminal_session path (e.g. the engine's own session JSONL sidecar) produces a RUN-provenance effort with a real cost block (tokens/time/$), finalized on every end path (finish, kill, close/park, reconcile-dead) — verified by a STUB-GATE suite with a pinned sidecar fixture, and by one live smoke run whose rollup delta matches the sidecar's reported usage.
- Honesty contract holds and is test-pinned: discovered/imported efforts still contribute exactly 0; a session whose usage genuinely cannot be captured surfaces an explicit 'unmeasured' state distinct from $0.00 in the rollup UI; no cost is ever estimated, interpolated, or fabricated — existing v4 rollup and v8 persist suites stay green unmodified.
- No double-counting: a session's persisted docs (source=discovered) and its new RUN cost record coexist without inflating the rollup — dedup keyed on session_id proven by a test that persists docs AND attaches cost for the same session, asserting the rollup counts the cost exactly once.
- The diag-B2 tile inconsistencies are REPRODUCED first (Playwright against captured registry-state fixtures: large-tile blank window, context-free blue restart, manual orientation), then fixed: after the fix, every tile class (running, parked-idle, done, failed, discovered/brownfield) click-opens a non-blank session window in Playwright with a screenshot sign-off.
- Resume narrates and orients: clicking a parked/done/discovered tile starts a session whose read-only orientation prompt AUTO-EXECUTES (loads docs/summary and prints what was done / accomplished / produced / next steps in the terminal), while any mutating/ACTION prompt remains v10 paste-NOT-submit — the fork is resolved, locked in the North Star doc, and pinned by a test asserting no ACTION prompt is ever auto-submitted.
- All constraints preserved: Python stdlib-only (pywinpty exception) passes distro.py's import scan; tests never touch the live :8777 service (stub PTY + ANCHOR_RUNNER_CMD + fake sidecar fixtures); resume/advance tests follow the v11/v11.1 lessons (worktree-only, conversation-only seeds the stub PTY buffer); the daily healthcheck gains a stubbed walk of the new capture+finalize path.
- The undercount is measured once: a before/after comparison on at least one real project quantifies how much spend the rollup was missing (turning derived-I1 from inferred to observed) and is recorded in the execution log.

> Every wave ships real source its new tests import and exercise; acceptance criteria follow the D16 hybrid convention (a one-line done-when + Given/When/Then for non-trivial waves).

## Wave 4 — W4 — Usage-Capture Pipeline: UUID-at-launch, ledger, eager finalize, capture-failed RED path

**Intent:** The core of the North Star: every interactive ConPTY session and every one-shot job leaves a machine-verified cost trail through ONE code path — UUID captured at launch (never mtime-guessed), sum-over-message parser against the pinned fixture, append-only idempotent ledger, eager finalize on every end path into Anchor's own durable snapshot, and the capture-failed RED path per the locked tripwire severity. Serves criteria (1),(3),(6).

**Deliverables:** engine_session_id capture AT LAUNCH (slug-dir watch within a tight window under the session lock, or PTY-banner parse per the W1 spike), stored on the registry record; uncaptured => honest state='uncorrelated'; Sum-over-message-usage parser against the pinned W1 fixture with explicit states measured / partial-resumed-elsewhere / unmeasured(reason) — never a guessed total; Capture-failed path: sidecar PRESENT but parse-raising or zero-usage-despite-message-lines => atomic state='capture-failed' record carrying the parse error class; never measured-$0, never silent unmeasured; session lifecycle always completes; Append-only usage ledger keyed by (engine_session_uuid, message_uuid/line-hash); re-ingestion idempotent; invariant test: switch_engine mid-session yields total = A-part + B-part counted once; Eager finalize on EVERY end path (kill, close/park, drain, finish, reconcile-dead) copying the usage snapshot into .anchor/; heartbeat snapshot piggybacked on the existing 120s autosave hook (no second timer); job_runner unification: durable-job stream-json usage (lane launches, Gandalf shards, summarizer runs) routed through the SAME ledger keyed by engine session UUID; Any ledger/capture inspection endpoint token-authed + added to the auth-enumeration test; STUB-GATE suite under the W2 fail-closed seam (temp ANCHOR_SIDECAR_DIR) covering all end paths + the corrupted-fixture capture-failed case

**Depends on:** W2
