Anchor — folder picker (Windows Explorer tree)

Click a folder row to expand it (its subfolders load underneath) and select it at the same time. Click again to collapse. Drill as deep as you like, then press ✓ Use this folder. Selecting auto-fills an editable Project name. (This prototype uses a fake in-memory filesystem; the real app fetches /api/rnd/dir_browse.)
