Paradigm 2 — Inline expanding panels (accordion decks) ✓ chosen

Each lane is a vertical column of tiles. Click a tile → it expands in place into a full-width panel that pushes the board down. Inside the panel the content stacks: summary on top, full-width terminal below — and you can drag the terminal's bottom edge to make it taller or shorter (try it in this mockup). Multiple panels stack down the page; minimize collapses back to the tile. No overlapping windows to manage — everything has a place.
