In every option the chip / breadcrumb appears only when there is a clear match — a build session whose source folder equals a planning session's source folder (e.g. both under planning/rnd-v4). A build session with no clear planning match shows no chip (honest — nothing fabricated).

☍ = link glyph · grey dot = imported/done · green dot = running. Clicking the chip/node opens (or focuses) the matched planning session's panel.
