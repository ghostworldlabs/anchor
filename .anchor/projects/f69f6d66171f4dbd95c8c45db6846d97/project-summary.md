## Objective

Anchor is a single-folder personal productivity and R&D command center that J.C. Liechty runs as a persistent local web service (`anchor_gui.py` behind the NSSM `anchor` service on localhost:8777), built on Python stdlib alone with plain markdown files as the source of truth. Its original job — tracking tasks, projects, and an inbox across academic, commercial, family, and writing domains — has grown into a "Mission Control" surface for AI-assisted engineering: per-project windows that launch and supervise live ConPTY terminal sessions running the researchPrime → Crucible → Foreman skill trio, each isolated in its own git worktree, with durable session records, validated summaries, cost rollups, handoff chains, and a Boneyard for discarded work. The system has been built out through roughly a dozen numbered waves (v2 "R&D Surface" through v12 "Efforts", plus the Gandalf deep-read tab and a telemetry/resume pass), all guarded by a large pytest suite and a 5 AM health check that exercises every surface against stubbed engines so no live model is ever called. Current work is on the `sharefix/v1.2.3` branch, focused on making Anchor safely shareable with collaborators — the last commits tightened the distro builder's declared-optional set, added share gates and a scrub-residue check, and wrote an honest release checklist and run contract. In parallel, active planning and build efforts are running on the "chamber" and "steward" tracks (chamber-m1-replace, steward-e1, steward-chamber) with a decision log on scaled Gandalf architecture; the working tree has substantial uncommitted changes across `anchor_gui.py`, the chamber modules, and the project-window front end. A prior comprehensive review flagged that sharing was blocked by open-by-default security and broken distro paths — the v1.2.x line is the direct response to that, and it is not yet pushed or verified on a clean machine.
