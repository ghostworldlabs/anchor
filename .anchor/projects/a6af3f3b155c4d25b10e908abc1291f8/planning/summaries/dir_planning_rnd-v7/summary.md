**North Star:** Make the project board an **honest, integrated, well-summarized view of all work**: 1. **Short, clean summaries.** Every *displayed short* summary (the project objective line, the per-tile blurb) is length-capped and **scrubbed of markdown/decorative glyphs** (`**`, `—`, `##`, backticks, the `✓` greeting, etc.). Full markdown stays only on the dedicated summary page. 2. **Live sessions live in their lane column.** A session started in research / plan / build / deliverables appears **as a tile in its lane column on the board the moment it starts** (green = running) and **stays there when done**

## Goal & key decisions

- This planning session ran the Crucible skill over the Anchor R&D project window to design version 7, called "Integrated Board", and it carried the work all the way from a locked North Star through a frozen Master Plan to a Foreman-ready Implementation Plan. The goal John locked at Stage 0 was to make the project board an honest, integrated, well-summarized view of everything happening in a project. Two decisions were settled with him along the way. First, every short summary shown on the board, meaning the project objective line and the per-tile blurb, will be run through a plain-text normalizer that strips markdown and decorative glyphs such as bold markers, dashes, headings, backticks and the greeting checkmark, and then capped to roughly a sentence for the objective and eight to twelve words for a tile; the existing generate-twice and grounding checks stay in place, and full markdown survives only on the dedicated summary page. Second, John approved Option B for live sessions: the top active strip keeps showing currently running sessions, and in addition every session started in a research, plan, build or deliverables lane appears as a tile in its own lane column the moment it starts, shown green while running, and stays there as a reopenable tile when it finishes, with the newest session prominent and older ones tucked under a "previous sessions" expander in the same pattern v6 introduced. The session produced three documents: the Master Plan capturing this frozen design, the Implementation Plan that breaks it into build waves for Foreman, and the Execution Log recording how the stages and Shark-Tank review rounds played out. Nothing was built here; the session's output is the vetted plan that a Foreman build session can pick up next.
