Mother Ship Workspace Root (Home Directory) anchor_settings.py

Your Workspace Root is the primary home folder on the Mother Ship where Anchor stores and automatically discovers your project folders (currently C:\dev on Puter—or e.g. D:\Projects or C:\Users\<name>\AnchorWorkspace if you prefer a different home folder). You can also attach standalone folders located anywhere else on your computer or ask Steward to find and copy scattered topic files into your root.

📂 Change Primary Workspace Root or Create a New Home Folder

Select an existing folder via Windows Explorer or type a new path below. If the folder doesn't exist yet on disk, click Create & Set as Root and Anchor will create it and update settings.json → host.project_roots[0] without touching existing files.
